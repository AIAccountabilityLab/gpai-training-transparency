Evaluation Notes

If you update your public summary, please let us know so that we can update the evaluation and scores. We also welcome suggestions on improvements to this page, e.g. see FAQ section.

The public summary for the Apertus Electronics HW LoRA can be found embedded in the model card on HuggingFace. The template contains good information on data selection, and explicitly enumerates its private datasets in a way few other summaries do. There are some possible inconsistencies in content, particularly regarding whether web crawling was done, and some fields are missing, however overall the summary represents a good effort at transparency. We assessed the summary's score to be 55.17% with Grade C for transparency, and 70.04% with Grade C+ for usefulness.
